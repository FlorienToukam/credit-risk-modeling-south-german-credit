# Data

The project uses the public **South German Credit** data set from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/573/south+german+credit+update).

To reproduce the analysis:

1. Download `SouthGermanCredit.asc` and `codetable.txt` from UCI.
2. Create `data/raw/` locally.
3. Save the downloaded files in `data/raw/`.

Raw data is excluded from the repository so the source remains attributable to UCI and the repository stays lightweight.
